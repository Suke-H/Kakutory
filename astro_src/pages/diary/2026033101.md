# パズルの着想


もともとは2024年8月の「Unity1週間ゲームジャム（通称：unity1week）」で制作したゲームとなります（[こちら](https://unityroom.com/games/kaerimichi)）。



「かえす」というお題があたえられたゲームジャム。共同制作しようと話してたけめるさんと、「かえす」は何がいいかなぁとアイデアを模索しました。色々考えたのですが、「かえす」というのが他動詞っぽいので、「キャラ操作するというより、導くようにして帰す」感じのゲームが作りたいなと思ってました。

なんとなくパズルになりそうだと思っていたのですが、そのときけめるさんに『[Veggie Quest](https://store.steampowered.com/app/2402170/Veggie_Quest_The_Puzzle_Game/?l=japanese)』や『[Automount](https://hempuli.itch.io/automount)』を紹介してもらいました。「Reverse Anti-Puzzle」と呼ばれているパズルジャンルで、「プレイヤー自身がパズルの設計士となり、最短経路を進むキャラをあえて遠回りさせるようなステージを作る」ゲーム性になっています。

このジャンルはまさに「導くように帰す」感じにぴったりだなと思い、この方向性が強まったのですが、これらのゲームは「真っ白キャンバスに点を打っていく」ような、クリエイティブ性が強く玄人向けなパズルです。

遊びやすくするためにも「有限個のパネル」を用意して、白黒反転でステージを操作させるようにし、制約を強める方向にしました。白黒反転が思いついたのも「かえす」というお題があったからです。こうして、枠組みとなる『unity1week版帰路』ができました！

# ギミックについて

unity1week後、まだこの枠組みには伸びしろがあるように思い、Steam版をぜひ作りたい！と決めました。
そこでギミックを追加すべく、色々模索しながら考えました。

結果として、最初からある「カラス・偽ゴール」に加えて、「オオカミ・休憩・切り貼り」を追加した形になります。
少し変わったパズルなので、ギミックを生み出すのが少し難しかった......

ですがパズルの枠組みとして、戦略性を色々生み出せそうな丈夫さを感じたので、そこは安心しながら作っていくことができました。
特に「切り貼り」は、参考にしていたAutomountに近いクリエィティブ性が出たかなと思い、お気に入りです。

ギミックを出す順番として、ワールドの並びを、
- 1面：白黒反転とカラス
- 2面：偽ゴールとオオカミ
- 3面：休憩
- 4面：切り貼り
- 5面：全て

という感じにしました。
どの面の始めでも「面白いじゃん！」とわくわくさせられていたら嬉しいです。

また、各ワールドにて「チュートリアルに近いステージから始めて、最後が一番難しくなる」ようにしてます。一本道のパズルなので特に意識しました。

自分が好きなステージを上げるとするなら、「2-11, 3-6, 4-6, ラスト2つ」です！🐦‍⬛🐺🪑✂

# パズルづくり

さて、パズルの枠組みとギミックが用意できて、そこからどうステージを作っていったかの話をします。

このパズルはステージ構想がそこそこ難しいです。白黒反転は紙で書くのが難しいし、経路自動探索もあるし。
そのため、パズルステージを構想するための「ステージエディタ」作成は先決でした。

結果的にWebエディタを作成しました。これならスマホでもステージを作れるぞ！（画像クリックで1-8が解けます）

ソルバーも用意しているので、ユーザーの方であってもこれを使ってゲームのステージを再現すれば、答えを教えてくれるぞ！（と言いたいけど休憩・切り貼りでエラーになるのを解決できてない🫠）

さて、これをパズル担当のacrocat君に使ってもらってステージ作成をお願いし、それを解いてコメントして、を繰り返してました。ほとんどのステージはacrocat君に作ってもらいました。

<img src="/images/2026033101/slack_2.png" alt="ステージエディタ" width="80%" />

作り方に関してほとんどをacrocatくんにお任せしてましたが、「気づきの順番」は大事にしてました。

- 休憩ステージは、初期位置が大事
- 休憩する前にカラスを取ると、休憩後にパネルを置けるようになる

など、「明示していない法則」をどう気づかせるか、そしてその気づきをどう活用してもらう順番をどうするかは意識しました。

かなり蛇足の話ですが、パズルって、ギミックという「明示されたルール」をまず作って、そこからの組み合わせをいろいろ考えたときに、「どういう法則が生まれるか」という話になる気がしていて、なんとなく数学の教科書っぽい感じに思います。「帰路学その1」みたいな。まだ開発側もわかってない法則が眠っていそう。

# ヒント

このゲームの特徴が「ヒント」だと思います。このゲームはストーリー好きな方にも遊んでほしいのと、ほかのパズルゲームと違い基本一本道なので、パズルのサポートは必須だと思っていました。

ただ、案外ヒントがあるパズルって少ないのかもしれません。参考材料が思いのほか見当たらず、どういう方法にするかは悩みました。

考えた結果、テキストベースにすることにしました。ストーリーとの親和性も高いし、工数的にもとても助かる。「左のしろおび、みのりちゃんの1つ右のマス」など、場所指定はどうしてもわかりずらいというのはありますが……

ヒントは「2つ」用意しました。気持ちはレイトン教授です。

- 気づき1：解き方を伝える
- 気づき2：ほぼ答え、だけど少しは余白を残す

もう気づき2に頼るということは「ヘルプ！」だと思うので、思い切ってほぼ答えにしつつ、それでも考える余白は残すような塩梅を目指してます。
詰まった方がいればすみません。ここは難しく、リリース後にプレイして頂いた配信を見ながら調整したりもしてました🙇‍♂️（ラストステージなど特に）。

「ヒントも読みたいから、パズルを解いたあとに読んでた」って方も見かけてうれしかったです。うれしかったわね......

# 苦労したこと

難易度調整は最後までやっていました。テストプレイで難しすぎるかなぁと気になった個所はパズルを調整したり、ヒントの塩梅を調整したり。

実装面での話をすると。「切り貼り」はかなりロジックぶっ壊しギミックで、中々の工数が持ってかれました。。「休憩をどうアンドゥするか？」に関しても、けっこう苦労したところではあります。


# 最後に

少し変わったパズル性だけど、新しいギミックの登場で「面白い！」と広がる感じがしつつ、戦略をじっくり考えらえるような奥深さがある、そんなパズルになっていたらとてもうれしい限りです！

パズルに関しては、acrocatくんのおかげがほんとに大きいです。お陰様でシンプルだけどしっかり難しいパズルステージたちが出来上がりました。帰路の枠組みで、ひたすら探求を進めてくれてステージを作り続けてくれて感謝......
